# Movia-skærme til The Bus

Mod til The Bus med Movia-design på bordcomputeren (Atron) og passagerskærmen:
billetsalg, login, pause-kort, eget skilt / "Ikke i rute" og skift rute undervejs.

Værktøjerne ligger i `MoviaTools/` og køres fra The Bus Modding (Unreal) via Python.
Se `CLAUDE.md` for arbejdsgangen.
